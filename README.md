# Glasswave

**Liquid Glass for Codex**

## 原项目与修改说明

**Glasswave 是基于 [Wangnov/Codex-App-Manager](https://github.com/Wangnov/Codex-App-Manager) 的定制修改版本，管理器本体和基础功能来自 Codex App Manager。** 本项目在原 Manager 基础上进行了一定程度的修改与扩展，主要包括 Liquid Glass 主题、Blur/Tint 控制、静态壁纸及相关界面与持久化调整。

- 原项目：[Codex App Manager](https://github.com/Wangnov/Codex-App-Manager)
- 原作者：[Wangnov](https://github.com/Wangnov)；感谢原作者及上游贡献者。
- 本版本所基于的上游提交：[`cc115b4`](https://github.com/Wangnov/Codex-App-Manager/commit/cc115b451c7268f6283610fe62597701e2bdab8f)。

Glasswave 为独立维护的修改版，非 Wangnov 或 OpenAI 官方发行。上游 Manager 的 MIT 许可与版权声明保留在发行包中。

## 下载与使用

本仓库保存 Glasswave 的 Windows portable 发行附件与使用入口。

当前版本：**0.4.0 RC2**（预发布版）。请进入 [Releases](https://github.com/daobenchu-boop/Glasswave/releases/tag/v0.4.0-rc.2) 下载 `Glasswave-0.4.0-RC2.zip`，查看版本说明并核对 SHA256。

完整解压后启动 `manager/apple-liquid-glass-manager.exe`，再导入包内 `.codexskin` 主题。详细使用与许可见压缩包中的说明文件。
