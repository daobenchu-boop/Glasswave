# Glasswave

**Liquid Glass for Codex**

本仓库保存 Glasswave 的 Windows portable 发行附件与使用入口。

当前版本：**0.4.0 RC2**（预发布版）。请进入本仓库的 **Releases** 页面下载 `Glasswave-0.4.0-RC2.zip`，查看版本说明并核对 SHA256。

完整解压后启动 `manager/apple-liquid-glass-manager.exe`，再导入包内 `.codexskin` 主题。详细使用与许可见压缩包中的说明文件。

Manager 为 Wangnov/Codex-App-Manager 的独立定制版，非上游或 OpenAI 官方发行。主题许可维持 personal-use。
